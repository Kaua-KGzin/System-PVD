Qualidade
Kauã
Fix race condition + paginação
Race condition: MAX+1 com concorrência pode duplicar. Solução: AutoIncrement nativo SQLite ou tabela de contador com lock. Paginação: ?page=1&pageSize=20 com PagedResponse<T>.
record PagedResponse<T>( IReadOnlyList<T> Items, int Page, int PageSize, int TotalCount, int TotalPages);
API
Pedro
