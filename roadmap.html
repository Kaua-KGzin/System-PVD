EF Migrations — eliminar EnsureCreated
O que está errado: DatabaseSeeder.cs:13 chama await db.Database.EnsureCreatedAsync(); — isso cria o schema sem histórico de versão, impossível fazer rollback ou evoluir o banco em produção.

Passo 1 — Microsoft.EntityFrameworkCore.Design já está no Pdv.Backend.csproj. Não instale nada.

Passo 2 — Instale o CLI global (se ainda não tiver): dotnet tool install --global dotnet-ef

Passo 3 — Dentro da pasta Pdv.Backend/, gere a migration inicial: dotnet ef migrations add InitialCreate Isso cria a pasta Pdv.Backend/Migrations/ com InitialCreate.cs e PdvDbContextModelSnapshot.cs.

Passo 4 — Em DatabaseSeeder.cs linha 13, troque: await db.Database.EnsureCreatedAsync(); por: await db.Database.MigrateAsync();

Passo 5 — Rode dotnet run e confirme no log que a migration InitialCreate foi aplicada sem erro. Depois, delete o arquivo pdv.db (SQLite local) e rode de novo — deve recriar tudo limpo via migration.

Regra: nunca usar EnsureCreated em nenhum ambiente. Toda mudança de schema daqui pra frente vira uma nova migration.
