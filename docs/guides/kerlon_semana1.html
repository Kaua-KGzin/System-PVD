SEMANA 1
Objetivo: Criar o projeto React 19 + TypeScript do zero na pasta frontend/, configurar as bibliotecas essenciais e construir a tela de Login conectada ao backend via Axios.
Passo a Passo — Setup
1
Criar o projeto React + TypeScript
Na raiz do repositório (System-PVD/):
npm create vite@latest frontend -- --template react-ts cd frontend npm run dev # abra http://localhost:5173
Se aparecer a tela padrão do Vite no browser, o ambiente está funcionando.
2
Instalar as dependências
npm install react-router-dom axios @tanstack/react-query zustand npm install -D @types/node
O que cada biblioteca faz
react-router-dom
Navegar entre páginas (Login → Dashboard). O "GPS" do app.
axios
Enviar e receber dados do backend via HTTP. O "carteiro" da app.
@tanstack/react-query
Cache inteligente para dados do servidor. Evita requisições desnecessárias.
zustand
Guardar estado global (usuário logado) entre telas diferentes.

Passo a Passo — Código
3
Configurar Axios com Interceptors (services/api.ts)
Interceptors são funções que rodam automaticamente em toda requisição — sem repetir código:
import axios from 'axios'; const api = axios.create({ baseURL: 'https://localhost:5235/api' }); // Adiciona o token JWT em TODA requisição automaticamente api.interceptors.request.use((config) => { const token = localStorage.getItem('token'); if (token) config.headers.Authorization = `Bearer ${token}`; return config; }); // Se o token expirar (401), desloga o usuário api.interceptors.response.use( (res) => res, (err) => { if (err.response?.status === 401) { localStorage.removeItem('token'); window.location.href = '/login'; } return Promise.reject(err); } ); export default api;
4
Criar a tela de Login (pages/Login/LoginPage.tsx)
Formulário com email, senha, estado de loading e mensagem de erro:
const [email, setEmail] = useState(''); const [password, setPassword] = useState(''); const [loading, setLoading] = useState(false); const [error, setError] = useState(''); const handleSubmit = async (e) => { e.preventDefault(); setLoading(true); try { const res = await api.post('/auth/login', { email, password }); localStorage.setItem('token', res.data.token); window.location.href = '/dashboard'; } catch { setError('Email ou senha inválidos.'); } finally { setLoading(false); } };
ℹ️ O endpoint /api/auth/login ainda não existe no backend (Kauã vai criar). Por enquanto vai dar erro de rede — isso é normal. Você está construindo a UI, ele está construindo a API. Vão integrar no Sync Day.
5
Configurar Rotas (App.tsx) + React Query (main.tsx)
// App.tsx — define as páginas import { BrowserRouter, Routes, Route, Navigate } from 'react-router-dom'; export default function App() { return ( <BrowserRouter> <Routes> <Route path="/login" element={<LoginPage />} /> <Route path="*" element={<Navigate to="/login" />} /> </Routes> </BrowserRouter> ); } // main.tsx — envolve tudo no QueryClientProvider const queryClient = new QueryClient(); ReactDOM.createRoot(...).render( <QueryClientProvider client={queryClient}> <App /> </QueryClientProvider> );
