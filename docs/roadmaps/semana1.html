Fix race condition nº venda + paginação
Race condition: MAX+1 com concorrência pode duplicar. Solução: usar AutoIncrement nativo SQLite ou tabela de contador com lock. Paginação: parâmetros ?page=1&pageSize=20, retornar PagedResponse<T> com TotalCount.
record PagedResponse<T>( IReadOnlyList<T> Items, int Page, int PageSize, int TotalCount, int TotalPages); API
Pedro
Sequência ou auto-increment p/ nº venda
Criar tabela SaleSequence com único registro e row-level lock, ou configurar EF para usar AUTOINCREMENT nativo. Garantir unicidade sem race condition.
