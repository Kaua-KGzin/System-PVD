Infra
Kauã
Rate limiting + structured logging
Rate limiting: fixed window 100 req/min por IP com Microsoft.AspNetCore.RateLimiting. Logging: usar ILogger corretamente com parâmetros estruturados. Log de cada venda: Id, valor, operador, terminal.
builder.Services.AddRateLimiter(opt => { opt.AddFixedWindowLimiter("api", w => { w.PermitLimit = 100; w.Window = TimeSpan.FromMinutes(1); }); }); API
Pedro
Avaliação: SQLite → PostgreSQL
SQLite não escala pra múltiplos caixas simultâneos com escrita concorrente. Avaliar migração: trocar Microsoft.EntityFrameworkCore.Sqlite por Npgsql.EntityFrameworkCore.PostgreSQL. Impacto: tipos DateTime, sequências, índices parciais.
dotnet add package Npgsql.EntityFrameworkCore.PostgreSQL # Ajustar connection string no appsettings # Testar migrations existentes DB
